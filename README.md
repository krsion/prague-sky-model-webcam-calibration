# Webcam calibration based on [J. F. Lalonde's implementation](https://github.com/jflalonde/webcamCalibration)

## Installation
run docker-compose run bash to install all dependencies and run bash in the container

## Running sky model calibration
Run `python3 main.py --help` to see all parameters needed for the script to work

## Running sun position calibration
Run `python3 sun_geometry.py` to run on data in `../data/p4p.json`.

## 3rd. party code

These folders are generated by `git subtree add ...` command and come from [J. F. Lalonde](https://github.com/jflalonde)
- webcamCalibration - https://github.com/jflalonde/webcamCalibration.git
- webcamCalibration/skyModel - https://github.com/jflalonde/skyModel.git
- webcamCalibration/utils - https://github.com/jflalonde/utils.git

Used git subtree instead of git submodule because of its simplicity. 
Didn't just copy-paste the code for better maintainability.
