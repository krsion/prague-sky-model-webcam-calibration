# Webcam calibration based on [J. F. Lalonde's implementation](https://github.com/jflalonde/webcamCalibration)

## Installation
- To successfully run `git clone [this repo url]` you need to have [Git LFS](https://git-lfs.com/) installed locally.
- Run docker-compose run bash to install all dependencies and run bash in the container

## Running sky model calibration
Run `python3 main.py --help` to see all parameters needed for the script to work

## Running sun position calibration
Run `python3 sun_geometry.py` to run on data in `../data/p4p.json`.

## 3rd party code

These folders are generated by `git subtree add ...` command and come from [J. F. Lalonde](https://github.com/jflalonde)
- webcamCalibration - https://github.com/jflalonde/webcamCalibration.git
- webcamCalibration/skyModel - https://github.com/jflalonde/skyModel.git
- webcamCalibration/utils - https://github.com/jflalonde/utils.git

Used git subtree instead of git submodule because of its simplicity. 
Didn't just copy-paste the code for better maintainability.

- Folder ArPragueSkyModelGroundXYZ is an unofficial version to work with XYX of original Prague Sky Model https://github.com/PetrVevoda/pragueskymodel by Petr Vevoda
- sky_image_generator.cpp wrapper to Python is self written but significantly inspired by Martin Mirbauer's [SkyGAN](https://cgg.mff.cuni.cz/publications/skygan-towards-realistic-cloud-imagery-for-image-based-lighting/) implementation which also uses Prague Sky Model

## 3rd party data
- data/webcams.json is copied from [CHMI](https://www.chmi.cz/files/portal/docs/meteo/kam/webcams.json)
- SkyModelDataset.dat [Google Drive](https://drive.google.com/file/d/19K96jEQmmqCeg8yjgZxj2awQj62lI50p/view)
- All images in folders `data` and `data-matlab` are originally produced by [CHMI](https://www.chmi.cz/) and processed by [KSVI MFF CUNI](https://ksvi.mff.cuni.cz/index.en.php)
- Sky masks in `data/masks` were originally produced by Matěj Mrázek ([GitHub](https://github.com/Matezzzz/Image_outpainting/))
